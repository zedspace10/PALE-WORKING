# Dependency security review

Last reviewed: 2026-09-16
Owner: PALE maintainers
Next review: 2026-10-16, or immediately before an Expo SDK upgrade

## Current production audit

`npm audit --omit=dev` reports no critical advisories, nine high-severity package records, and thirteen moderate package records. The high records all trace to six advisories in two build-time leaf dependencies bundled through Expo SDK 54 and Metro. The moderate records trace to the two advisories documented below. `npm audit fix` has applied every compatible non-forced remediation. npm's remaining proposed fixes require breaking Expo/Expo Router changes outside this SDK 54 compatibility change.

Neither dependency is imported by the PALE application bundle or static landing server at runtime. PALE also has no user-upload path that passes images, CSS, or source maps to Metro. The remaining exposure is therefore limited to a local or CI export processing a malicious repository-controlled build asset.
